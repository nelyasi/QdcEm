API Outline
===========

The QdcEm package is organised into four modules. Each module page
gives the full function signatures, parameter descriptions, and return
values.

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Module
     - Description
   * - :doc:`modules/remotegates`
     - Cat-Comm and teleportation-based distributed gate library.
   * - :doc:`modules/qpu`
     - QPU data structure (``Make``) and initial-layout helper
       (``Get_Initial_Layout``).
   * - :doc:`modules/algorithms_module`
     - Distributed Bell-state, Grover's Search, and QFT circuits.
   * - :doc:`modules/representation`
     - Plotting utilities and custom circuit display styles.
